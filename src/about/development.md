# 我和开发

<div class="page-meta">持续更新</div>

我接触开发，不是从一个完整的大项目开始，而是从一次次具体问题开始：安装工具、运行代码、理解报错、修改网页，再把过程记录下来。

## 为什么开始

开发让我能够把想法变成可以运行、可以检查、也可以继续修改的东西。比起只记住一个结论，我更希望理解它为什么成立，以及怎样重新做出来。

## 我正在做

- 用 C/C++ 学习程序与系统；
- 用 Verilog 理解数字电路和处理器；
- 用 Git 与 GitHub 管理代码和网站；
- 用 Markdown 与 mdBook 整理长期笔记；
- 用 Codex、ChatGPT 等工具辅助查错、理解和实现。

## 我的方式

我更喜欢从一个小而明确的目标开始：先让它运行，再理解过程，最后整理成别人也能复现的记录。

开发对我而言不只是写代码，也包括环境配置、问题定位、界面设计、内容组织和持续维护。

## 之后

继续完成一生一芯 E5，补充开发实践，并把真正解决过的问题整理成简洁、可靠的教程。
