# 电话验证说明

<div class="page-meta">工具获取 · 合规验证</div>

平台的验证要求可能随地区、产品和风控状态变化。实际操作时应以页面当前提示和官方帮助文档为准。

## 基本原则

- 使用本人能够长期控制的号码；
- 不购买来源不明的批量账号或接码服务；
- 不向他人发送短信验证码；
- 不尝试绕过平台的安全和地区限制；
- 验证失败时检查国家区号、号码格式和短信拦截设置。

## 常见排查

1. 确认号码和国家区号正确；
2. 检查手机是否能够正常接收短信；
3. 等待合理时间后再重试，避免连续高频请求；
4. 查看平台官方帮助中心；
5. 仍无法解决时联系官方支持。
