# ChatGPT 获取与使用

<div class="page-meta">工具获取 · 账号</div>

## 入口

从 ChatGPT 官方网站使用，软件我目前未找到合适的使用方法。不要从网盘、论坛或评论区安装所谓浏览器插件版。

## 账号

- 使用自己能够长期访问的邮箱，qq邮箱或谷歌邮箱都可以；
- 不在公开仓库提交 API Key；
- 正常登陆后的免费版能力已经很强了，只是在多模态方面有限制;
- go我不太建议如果只是想尝试可以试试，plus就足以适应99的场景了而且送codex的额度，再高就是专业开发者使用，我并不了解。
- 中转站也可以，日抛号也行，但相比之下稳定的代充更好，如果你可以自行充值当然更好，这只是我了解的使用方法，且存在风险仅参考。

## 网页端还是客户端

网页端适合快速使用，不需要额外安装；桌面客户端更适合频繁调用、文件操作和系统集成。选择哪一种主要取决于自己的工作流。
