# ChatGPT 获取与使用

<div class="page-meta">工具获取 · 账号与客户端</div>

## 官方入口

优先从 ChatGPT 官方网站或操作系统官方应用商店获取客户端。不要从网盘、论坛或不明下载站安装所谓“破解版”“增强版”。

## 账号安全

- 使用自己能够长期访问的邮箱；
- 开启可用的账号安全设置；
- 不共享密码、验证码或登录会话；
- 不在公开仓库提交 API Key；
- 遇到登录异常时先核对域名和客户端来源。

## 网页端还是客户端

网页端适合快速使用，不需要额外安装；桌面客户端更适合频繁调用、文件操作和系统集成。选择哪一种主要取决于自己的工作流。
